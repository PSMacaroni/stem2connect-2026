## Who can enter
Students aged 13 or older, enrolled in middle school, high school, college or university. Solo or teams of up
to 6. Each person is on one team only. Each team submits one project. No coding experience needed.

## Tracks (pick one primary track)
Education, Healthcare, Sustainability, Scientific Research, Community Impact. Tracks are starting points, not
limits. State the track in the additional-details question or in the public Devpost description.

## What must be submitted on Devpost by the deadline
Missing any of these makes the entry ineligible.
1. **GitHub repository**: public, with the source code and a README that explains what the project does, how to
   run it, and which AI tools or services it uses.
2. **Demo video**: YouTube or Vimeo, 6 minutes or less, publicly visible or unlisted, showing the project working.
3. **Project description** on the Devpost form: project name, the problem, how it uses AI, what the team learned.
4. **Track selection.**
5. **All team members added** to the submission on Devpost.

Teams can edit the submission until the deadline. The project must be a working solution that can be
demonstrated (website, app, chatbot, data tool). Slide decks, mockups and concept descriptions alone do not qualify.
Judges must be able to open the project or see it working in the video.

## Rules that are easy to trip on
- **New work only.** The project must be created between Oct 11 and Nov 21, 2026. Open-source libraries, public
  datasets and third-party APIs are allowed but **must be credited in the README**. Anything reused from an
  earlier project has to be checked against this rule and disclosed. Code that predates Oct 11 is the risk.
- **AI disclosure.** AI coding assistants are allowed with disclosure and attribution. Say which tools you used
  and what they contributed, in the README and the Devpost description.
- An AI feature inside the project is strongly recommended. It is not mandatory for people without API credits;
  those projects are not automatically scored zero on "Use of AI". The event page lists free options under Resources.
- No harmful, offensive or misleading content. Do not collect users' personal data without consent.
- Original work that does not infringe anyone's IP. Teams own what they make.

## Judging: five criteria, 20% each
1. Problem and Impact: a real, clearly defined problem; a meaningful difference for the people it is for.
2. Use of AI: AI meaningfully supports the solution, and AI coding help is disclosed.
3. Functionality: it works as shown and is usable, not only a concept.
4. Learning and Growth: the team stretched beyond what it knew and can explain what it learned.
5. Presentation: problem, solution and next steps are clear in the demo video and the Demo Day presentation.

A tie goes to the higher Problem and Impact score. Judging decisions are final.

## Prizes
Exactly 3 winning projects: Gold, Silver, Bronze. Each gets a certificate, connections to other AI programs and
mentorship, and a spotlight post on STEM2Connect's social channels. No project wins more than one prize.
Anyone who submits a complete project and presents on Demo Day can ask for a participation certificate.
The event page also lists free .xyz domains for eligible submitting teams (boilerplate code does not qualify);
the Rules page does not mention them, so treat that as unconfirmed.
